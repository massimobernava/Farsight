# Changelog

This plugin's version tracks `farsight-server`'s own package version (see
`packaging/server/build.sh`, which stamps the current build's version into `plugin.json` at build
time) — it isn't released independently. See the main
[Farsight](https://github.com/massimobernava/Farsight) repository's commit history/releases for
what actually changed and when.
