Farsight

Remote desktop, SSH, and fleet monitoring —
self-hosted, over your own Tailscale network.

Most teams pay per-seat for TeamViewer or AnyDesk to do something that, on a private network you already control, never needs to leave that network at all. Farsight does it self-hosted, free, with no artificial device limits.

View on GitHub Install Releases

What you get

Remote desktop from the browser

VNC over Tailscale, no client install, no relay servers — traffic goes device-to-device inside the VPN.

SSH

Plain SSH over the same private network. Nothing extra to configure.

Fleet monitoring

Live online/offline status and historical metrics via Grafana, out of the box, for every device.

No public exposure, ever

Every service binds to the Tailscale interface only. Nothing to firewall, because nothing listens outside the VPN.

Multi-tenant

Multiple isolated customers or teams on one server, with per-tenant device scoping.

LLM assistant

Natural-language queries over telemetry and anomaly triage — any OpenAI-compatible provider, local (Ollama) or hosted (OpenRouter).

prototype, actively developed

Roadmap

  • ✓ Browser-based remote desktop (VNC over Tailscale, no relay, no third party)
  • ✓ SSH access over the same private network
  • ✓ Fleet monitoring & dashboard (online/offline status, per-device naming)
  • ✓ Historical metrics (Grafana)
  • ✓ Multi-tenant (multiple isolated customers/teams on one server)
  • ✓ LLM assistant — natural-language queries over telemetry, anomaly triage
  • ○ Fine-grained audit trail (who accessed which device, when)
  • ○ Headscale support as a drop-in alternative to Tailscale

Quick start

Server (one dedicated machine)

export TS_AUTHKEY=tskey-auth-...
curl -fsSL https://raw.githubusercontent.com/massimobernava/Farsight/main/packaging/server/install.sh \
  | sudo -E bash

Client (every monitored machine)

export TS_AUTHKEY=tskey-auth-...
curl -fsSL https://raw.githubusercontent.com/massimobernava/Farsight/main/packaging/client/install.sh \
  | sudo -E bash

TS_AUTHKEY is only needed if the machine isn't already on your Tailscale network. Full setup and configuration: README.

Managed hosting

Everything above is free to self-host. If you'd rather not run the infrastructure yourself, that's the paid offering — a private control-plane server (Headscale-based, one subscription instead of per-seat pricing) and, if you want the LLM assistant, a set number of tokens included per month. Interested? Open an issue on the repo.
